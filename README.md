# BRONIES .99 Training

Mobile-first training plan builder for the Bronies running crew.

## Themes
Switch between **Default** and **8-BIT** using the 🎨 Theme button in the header.
Choice is saved — next visit opens in whichever skin you left it on.
Press Start 2P font (8-bit) is lazy-loaded only when that skin is activated.

## Stack
- React 18 + Vite · Deployed on Vercel
- @formspree/react · @sentry/react

## Dev
```bash
npm install
npm run dev
```
